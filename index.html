O problema

O painel diz uma coisa. A vaga diz outra.

VAGA A-15
LIVRE
≠

Motorista entra, não acha a vaga, dá ré… fila e buzina.

Como fazer o sistema saber sempre se a vaga está livre ou ocupada?

Abertura (2 min). “Imagine a entrada de um shopping. O painel diz LIVRE, mas tem carro lá. O que acontece?” Deixe responderem.

Avance: fila, buzina. Depois a pergunta-guia da aula.

Feche com: “Nosso programa vai guardar o estado da vaga e nunca deixar ele ficar errado.”

Objetivo de hoje

O que vamos construir (e o que a prova pede)

  • 2getter e setter para cada um

  • 4retirarVeiculo() — registra a saída

  • um setor — Coberto
  • um andar — 1

(4 min) Pergunte antes de avançar cada item. “O que uma vaga tem? O que identifica ela?” Revele conforme a turma responder.

Depois: “E o que uma vaga faz? Que ações acontecem com ela?”

Conclusão no quadro: TEM = atributos · FAZ = métodos. Essa frase resolve metade da prova.

No estacionamento com manobrista, você não entra na garagem para mexer nos carros. Você pede para ele.

Parte 2 · A regra

A vaga só tem dois estados

Estacionar muda true → false. Retirar muda false → true.

(3 min) Desenhe isto no quadro também. Revele as setas uma a uma.

Primeiro as duas ações válidas. Depois pergunte: “E se eu tentar estacionar numa vaga ocupada?” → nada muda, aparece a mensagem.

Frase-chave: estacionar true → false; retirar false → true.

Checkpoint · Passo 5

Getters e setters: deixe o IntelliJ escrever

Alt+Insert → Getter and Setter → Ctrl+A → OK
Getter = consultar. Devolve o valor com return.
Setter = guardar. Recebe o valor entre os parênteses.
this.identificacao é o atributo deste objeto; o outro é o valor que chegou.
Para boolean o getter usa is: isDisponivel(). É normal.
public String getIdentificacao() {
    return identificacao;
}

public void setIdentificacao(String identificacao) {
    this.identificacao = identificacao;
}

public boolean isDisponivel() {
    return disponivel;
}

O IntelliJ gera 8 métodos (4 getters + 4 setters). Aqui mostramos só 3 como exemplo.

(3 min) Faça o Alt+Insert devagar, mostrando a lista e o Ctrl+A.

Depois de gerar, abra um getter e um setter e explique com este slide.

O this costuma confundir: “tem duas coisas com o mesmo nome; o this aponta para a que é do objeto”.

Checkpoint · Passo 6

estacionar() — registrar a entrada

public void estacionar() {
    if (disponivel) {
        disponivel = false;
        System.out.println("Entrada registrada! Veículo estacionado na vaga " + identificacao + ".");
    } else {
        System.out.println("Vaga já ocupada");
    }
}
void e (): não recebe, não devolve.
if (disponivel) pergunta: está livre?
Sim → ocupa (true → false) e confirma.
Não → avisa. Texto exato: Vaga já ocupada

Digite no IntelliJ abaixo dos getters/setters. Fale enquanto digita: “se está livre… ocupa… e avisa”.

Ligue cada parte com a matriz 2×2: o if é a célula do teste 1, o else é a do teste 2.

Checkpoint · Passo 6

retirarVeiculo() — registrar a saída

public void retirarVeiculo() {
    if (!disponivel) {
        disponivel = true;
        System.out.println("Saída registrada! Vaga " + identificacao + " liberada.");
    } else {
        System.out.println("A vaga não está ocupada");
    }
}
! significa NÃO. Lê-se: “se não está disponível…”
true → ! → false
false → ! → true
o ! inverte
Ocupada → libera (false → true) e confirma.
Livre → avisa: A vaga não está ocupada

O ! é o ponto mais difícil. Leia em voz alta: “if NÃO disponível”.

Opção de erro planejado: digite sem o !, siga em frente e só descubra ao rodar no passo 9.

Checkpoint · Passo 7

Classe Main: criar e preencher a vaga

package atividade;

public class Main {
    public static void main(String[] args) {

        Vaga vaga = new Vaga();

        vaga.setIdentificacao("A-15");
        vaga.setSetor("Coberto");
        vaga.setAndar(1);
        vaga.setDisponivel(true);

        System.out.println("=== Dados da vaga ===");
        System.out.println("Identificação: " + vaga.getIdentificacao());
        System.out.println("Setor: " + vaga.getSetor());
        System.out.println("Andar: " + vaga.getAndar());
        System.out.println("Disponível: " + vaga.isDisponivel());
main é a porta de entrada. Por enquanto, decore essa linha.
new Vaga() fabrica o objeto. vaga é o nome dele.
Setters guardam os dados. Valores à sua escolha.
Começa livre: true. Sem isso, o teste 1 falha!
Getters consultam. O + cola texto com valor.

Atalho: digite psvm + Tab para gerar o main, e sout + Tab para o System.out.println.

Destaque o setDisponivel(true): é o erro mais comum da prova.
